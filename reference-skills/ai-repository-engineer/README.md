# AI Repository Engineer

A reference Skill candidate for repository-level AI engineering.

## Goal

Help an agent create, understand, audit, and evolve repositories using evidence-driven decisions.

## Modes

- Create: build repository structures and templates.
- Analyze: understand existing repositories and produce architecture views.
- Evolve: improve repositories while preserving behavior.

## Benchmark Usage

This Skill is evaluated through:

- repository-engineering benchmarks;
- template-generation benchmarks;
- skill-architecture benchmarks.

The evaluation focuses on engineering quality, not only final output quality.
