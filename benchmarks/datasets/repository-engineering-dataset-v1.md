# Repository Engineering Dataset v1

## Purpose

A first benchmark dataset for evaluating AI repository engineering skills.

The dataset focuses on whether a Skill can understand, create, and evolve repositories safely.

## Cases

### Case 01 — Unknown Repository Analysis

Input:
- Existing repository with incomplete documentation
- Mixed conventions
- Multiple configuration surfaces

Expected capabilities:
- Extract repository map
- Identify ownership boundaries
- Separate facts from assumptions
- Produce architecture notes

Evaluation:
- Evidence quality
- Architecture accuracy
- Risk identification

---

### Case 02 — Repository Template Creation

Input:
- Project goal
- Technology constraints
- Expected growth path

Expected capabilities:
- Generate minimal scalable structure
- Define documentation surfaces
- Define validation points

Evaluation:
- Structure quality
- Maintainability
- Future evolution

---

### Case 03 — Safe Repository Evolution

Input:
- Existing repository with technical debt

Expected capabilities:
- Analyze current state
- Propose target state
- Minimize breaking changes
- Define verification steps

Evaluation:
- Preservation
- Migration safety
- Change impact analysis
