# Repository Test Corpus

## Purpose

Controlled repository scenarios for evaluating repository-oriented skills.

Each case should test the same capabilities across different Skill candidates.

## Evaluation Goals

- Repository understanding
- Evidence-based architecture analysis
- Change impact reasoning
- Safe improvement planning
- Maintainability assessment

## Cases

### Legacy Monolith

Tests:
- boundary discovery
- dependency analysis
- refactor planning

### AI Agent Repository

Tests:
- skill ownership
- context routing
- instruction hierarchy
- tool boundary design

### Growing Frontend Repository

Tests:
- component organization
- state ownership
- documentation quality
- architecture drift detection
