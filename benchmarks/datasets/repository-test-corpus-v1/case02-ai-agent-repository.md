# Case 02 — AI Agent Repository

## Purpose

Evaluate whether a Skill can understand an AI Agent codebase with multiple context, tool, and instruction boundaries.

## Scenario

A repository contains:

- Agent runtime
- Tool integrations
- Prompt/skill definitions
- Memory/context layer
- Evaluation pipeline

## Expected Analysis

The Skill should identify:

- Ownership boundaries
- Context flow
- Tool contracts
- Skill loading strategy
- Failure points

## Evaluation Focus

- Evidence before assumptions
- Separation of runtime and instructions
- Maintainable architecture suggestions
- Change impact awareness
