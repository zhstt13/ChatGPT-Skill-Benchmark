# Case 03 — Growing Frontend Repository Input Specification v1

## Purpose

Define a controlled input scenario for evaluating repository analysis skills on evolving frontend systems.

## Benchmark Focus

- Component boundaries
- State ownership
- Shared utilities
- Design system consistency
- Performance risks
- Safe evolution planning

## Required Skill Output

The evaluated Skill should provide:

1. Current frontend architecture map
2. Dependency and ownership analysis
3. Maintainability risks
4. Migration priorities
5. Low-risk improvement roadmap

## Rules

- Preserve existing behavior unless change is justified.
- Distinguish observed issues from assumptions.
- Consider impact before recommending structural changes.
