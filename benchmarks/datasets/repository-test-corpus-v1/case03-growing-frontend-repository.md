# Case 03 — Growing Frontend Repository

## Purpose

Evaluate Skill ability to analyze a frontend project that has grown over time.

## Scenario

A repository contains:

- UI components
- Pages/routes
- State management
- Shared utilities
- Design assets
- Documentation gaps

## Expected Analysis

The Skill should identify:

- Component boundaries
- State ownership issues
- Duplicate logic
- Design system opportunities
- Performance risks

## Evaluation Focus

- Preserve existing behavior
- Avoid unnecessary rewrites
- Prioritize high-impact improvements
- Provide migration-safe recommendations
