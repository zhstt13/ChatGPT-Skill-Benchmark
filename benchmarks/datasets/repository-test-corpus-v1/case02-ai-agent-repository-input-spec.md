# Case 02 — AI Agent Repository Input Specification v1

## Purpose

Define a controlled input scenario for evaluating repository analysis skills on AI Agent projects.

## Benchmark Focus

- Agent architecture understanding
- Tool boundary analysis
- Skill and context separation
- Runtime flow analysis
- Evaluation pipeline awareness

## Required Skill Output

The evaluated Skill should provide:

1. Current architecture map
2. Component ownership analysis
3. Tool and context boundary review
4. Risks and unknowns
5. Safe improvement plan

## Rules

- Analyze current state before proposing changes.
- Separate facts, assumptions, and unknowns.
- Avoid redesign without evidence.
