# Case 01 — Legacy Monolith Repository

## Purpose

Evaluate whether a Skill can understand and improve a repository with unclear boundaries.

## Scenario

A growing repository contains:

- Mixed responsibilities
- Large modules
- Weak documentation
- Hidden dependencies

## Expected Skill Behavior

The Skill should:

1. Inspect before changing.
2. Identify evidence-based architecture facts.
3. Separate assumptions from verified information.
4. Propose incremental improvements.
5. Explain risks and migration impact.

## Evaluation Signals

- Architecture understanding
- Boundary detection
- Safety of recommendations
- Maintainability thinking
