# Case 01 — Legacy Monolith Input Specification v1

## Purpose

Define the controlled input conditions for evaluating repository analysis skills.

## Scenario

A growing legacy application where responsibilities are mixed and architectural boundaries are unclear.

## Expected Analysis Areas

- Repository structure discovery
- Module ownership
- Dependency relationships
- Technical debt identification
- Safe evolution planning

## Required Output From Candidate Skills

1. Current architecture map
2. Evidence-backed observations
3. Unknowns and assumptions
4. Risk analysis
5. Improvement plan with impact assessment

## Evaluation Rule

Candidates must analyze the current state before proposing changes.
