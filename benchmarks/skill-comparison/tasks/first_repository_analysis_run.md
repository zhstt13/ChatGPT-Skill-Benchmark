# First Repository Analysis Benchmark Run

## Objective
Compare a baseline repository analysis skill against AI Repository Engineer on the same repository understanding task.

## Task
Given an unknown repository, produce:

1. Repository structure map
2. Architecture overview
3. Main dependencies
4. Potential risks
5. Improvement suggestions

## Evaluation

| Category | Weight |
|---|---:|
| Evidence quality | 20 |
| Architecture accuracy | 25 |
| Completeness | 20 |
| Maintainability insight | 20 |
| Actionability | 15 |

## Expected Output

Each run must include:

- Skill name and version
- Repository analyzed
- Evidence collected
- Final report
- Score breakdown
- Reviewer notes
