# Repository Architect vs Baseline Skill

## Goal
Compare a simple repository analysis skill against an advanced repository engineering skill on the same task.

## Shared Task
Given an unknown repository, produce:

- Repository structure summary
- Architecture overview
- Key dependencies
- Risks and technical debt
- Improvement suggestions

## Participants

### Baseline Skill
Expected behavior:
- Basic file understanding
- Simple summary
- General recommendations

### Advanced Skill
Expected behavior:
- Evidence-first analysis
- Architecture boundaries
- Dependency reasoning
- Change impact awareness
- Evolution planning

## Evaluation

Score each output using:

- Evidence quality
- Architecture accuracy
- Completeness
- Maintainability
- Actionability

Total score: 100
