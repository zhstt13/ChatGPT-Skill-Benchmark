# Skill Comparison Benchmark

## Purpose

This benchmark compares different Skill implementations on the same task.

The goal is not only measuring final output quality, but also evaluating engineering quality:

- Architecture
- Context handling
- Maintainability
- Reusability
- System integration

## Comparison Model

```text
Baseline Skill
      vs
Advanced Skill
      ↓
Same Task
      ↓
Same Evaluation Rubric
      ↓
Score Comparison
```

## Initial Candidates

### Baseline
A minimal single-file Skill implementation.

### AI Repository Engineer
A modular Skill implementation using:

- Create workflow
- Analyze workflow
- Evolve workflow
- Evidence-first reasoning

## Evaluation Areas

1. Task completion
2. Architecture quality
3. Context management
4. Maintainability
5. Integration capability
