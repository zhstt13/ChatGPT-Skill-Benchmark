# Legacy Monolith Sample Repository

## Purpose
A controlled repository sample for evaluating architecture analysis skills.

## Structure

```
app/
├── controllers/
├── services/
├── models/
├── database/
└── utils/
```

## Hidden Evaluation Targets

- Detect high coupling between services and controllers.
- Identify unclear ownership boundaries.
- Separate observed facts from assumptions.
- Suggest incremental migration steps.
