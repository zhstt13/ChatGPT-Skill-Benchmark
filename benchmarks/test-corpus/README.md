# Repository Test Corpus v1

Controlled repositories and scenarios for evaluating repository engineering skills.

## Cases

- legacy-monolith: architecture discovery and safe refactoring analysis.
- ai-agent-project: context flow, tool boundaries, and skill ownership.
- frontend-growth-problem: maintainability, component boundaries, and scaling issues.

Each case should define:
- observed facts
- hidden issues
- expected analysis
- evaluation criteria
