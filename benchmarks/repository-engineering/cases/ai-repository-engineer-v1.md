# Benchmark Case: AI Repository Engineer v1

## Goal
Evaluate whether a skill can safely analyze, improve, and evolve a software repository.

## Scenario
A repository contains multiple modules, incomplete documentation, repeated instructions, and unclear ownership boundaries.

## Required Behaviors

1. Discover repository structure before editing.
2. Identify missing context and assumptions.
3. Separate verified facts from recommendations.
4. Propose reversible changes first.
5. Validate changes after implementation.
6. Produce a concise change report.

## Evaluation Focus

- Repository understanding
- Architecture reasoning
- Preservation of existing functionality
- Documentation quality
- Validation discipline
- Ability to evolve without unnecessary complexity
