# Canonical Run Records

Store a raw, unedited model output as `<run-id>.md` and its matching `<run-id>.json` Run Record here. Do not overwrite an existing run: repeated runs are data, not noise.

`draft` records may exist while evidence is being collected. Only `complete` records are eligible for a published comparison, and the validator rejects a complete record with incomplete metadata, invalid score arithmetic, stale Candidate blob, missing raw output, missing fixture evidence, or mismatched Case ID.
