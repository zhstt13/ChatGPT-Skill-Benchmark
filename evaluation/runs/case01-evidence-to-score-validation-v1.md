# Case 01 Evidence to Score Validation v1

## Purpose
Validate the transition from reviewed evidence into scoring.

## Pipeline

Input Lock
→ Candidate Outputs
→ Evidence Mapping
→ Evidence Review
→ Evidence-to-Score Validation
→ Final Score
→ Comparison Report

## Validation Rules

- Every score item must reference supporting evidence.
- Unsupported claims must not affect scoring.
- Facts, assumptions, and unknowns remain separated.
- Candidate A and Candidate B must use identical evaluation criteria.
- Raw outputs remain immutable after capture.
