# Case 01 — Final Scoring Execution Gate v1

## Purpose

This gate defines the final validation point before producing the first benchmark score.

## Flow

```
Candidate Outputs
      ↓
Evidence Mapping
      ↓
Evidence Review
      ↓
Scorecard Validation
      ↓
Final Score
      ↓
Comparison Report
```

## Validation Rules

- Every score must reference validated evidence.
- Raw outputs must remain unchanged.
- Facts, assumptions, and unknowns must remain separated.
- Both candidates must be evaluated under identical input conditions.
