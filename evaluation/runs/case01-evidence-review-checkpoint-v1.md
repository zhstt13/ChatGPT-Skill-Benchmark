# Case 01 Evidence Review Checkpoint v1

## Purpose

Checkpoint between evidence mapping and rubric scoring.

## Flow

Input Lock
→ Candidate Outputs
→ Evidence Mapping
→ Evidence Review
→ Rubric Scoring
→ Comparison Report

## Review Rules

- Every finding must reference supporting evidence.
- Facts, assumptions, and unknowns must remain separated.
- Raw outputs must not be modified during review.
- Scores are only assigned after evidence validation.
