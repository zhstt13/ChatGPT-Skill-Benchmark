# Benchmark Execution Checklist v1

## Purpose

Standardize the execution process before recording Skill comparison results.

## Pre-run Validation

- [ ] Select benchmark case
- [ ] Record Skill version
- [ ] Record model configuration
- [ ] Confirm identical input for all candidates
- [ ] Capture raw outputs

## Evaluation Process

### Evidence Review

- [ ] Facts separated from assumptions
- [ ] Claims supported by repository evidence
- [ ] Missing information explicitly identified

### Architecture Review

- [ ] Current architecture described
- [ ] Boundaries identified
- [ ] Dependencies analyzed
- [ ] Risks documented

### Improvement Review

- [ ] Recommendations are actionable
- [ ] Changes preserve existing behavior
- [ ] Migration impact is considered

## Final Recording

- Score rubric completed
- Strengths documented
- Weaknesses documented
- Next improvement iteration defined
