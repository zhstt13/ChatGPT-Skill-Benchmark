# Case 01 Real Benchmark Run Review Checklist v1

## Purpose

Final review gate before converting execution artifacts into benchmark results.

## Review Flow

```text
Run Outputs
    ↓
Evidence Review
    ↓
Rubric Validation
    ↓
Score Approval
    ↓
Comparison Report
```

## Validation Checklist

- [ ] Same input used for both candidates
- [ ] Raw outputs preserved
- [ ] Evidence linked to findings
- [ ] Facts separated from assumptions
- [ ] Unknowns explicitly recorded
- [ ] Scores justified by evidence
- [ ] Comparison conclusions trace back to rubric
