# Legacy Evaluation Artifacts

This directory is preserved as historical prototype material. It contains early templates, drafts and scenario-only notes created before the Canonical v1 contracts existed.

Do not use it as the source of a current benchmark score, case definition or scoring weight. Canonical ownership now lives in `benchmark/manifest.json`, `benchmark/scoring.json`, `benchmark/run.schema.json` and `benchmark/cases/`.

New raw outputs and Run Records belong in `benchmark/runs/`; derived, validated summaries belong in `benchmark/results/`.
