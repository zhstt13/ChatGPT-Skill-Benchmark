# Case 01 — Legacy Monolith Scoring Procedure v1

## Purpose

Define the process for converting collected benchmark evidence into measured scores.

## Scoring Rules

Scores must be based on recorded evidence only.

No score should be assigned from assumptions or expected behavior.

## Evaluation Flow

1. Review AI Repository Engineer evidence.
2. Review Baseline Repository Skill evidence.
3. Validate findings against Ground Truth.
4. Assign category scores.
5. Record strengths, weaknesses, and missing evidence.

## Categories

| Category | Weight |
|---|---:|
| Evidence Quality | 20 |
| Architecture Quality | 25 |
| Maintainability | 20 |
| Output Quality | 20 |
| Integration | 15 |
